# Homepage mockups

Four self-contained HTML mockups for ferreirademelo.com. Open any file directly in a browser — no build step, no dependencies.

| File | Direction | In one line |
| --- | --- | --- |
| `mockup-1-professional.html` | Clean & professional | Swedish-modern calm: off-white ground, pine-teal accent, serif headings, ledger-style note list, sidebar with About/Now. |
| `mockup-2-fun.html` | Fun (grown-up playful) | Warm café energy: bold Trebuchet type, tilted sticker cards with offset shadows, squiggle underlines, rotating "Arbete pågår" badge, Hej/Oi/Hello greeting. |
| `mockup-3-3d.html` | Creative / 3D | "Norrsken" — dark arctic sky with animated aurora, perspective grid floor, mouse-parallax 3D hero, floating glass note cards. |
| `mockup-4-fieldnotes.html` | Designer's choice | "Fältanteckningar" — the site as a literal working notebook: dotted-grid paper, fountain-pen ink, red-pen marginalia, taped index cards, a Now checklist, EN/SV labels. Takes "show process, not polish" literally. |

All four use the real site content (notes, BudgetApp, bio). Mockups 1, 2 and 4 support light + dark themes; mockup 3 deliberately commits to a single dark scene. All respect `prefers-reduced-motion`.
