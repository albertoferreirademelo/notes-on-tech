# Homepage mockups — round 2

Four ambitious directions evolved from the round-1 winner (fältanteckningar). All are notes-first: projects are deliberately demoted to a compact, dateless "workbench" strip so they can never look stale. Self-contained HTML — open any file in a browser.

| File | Direction | The "wow" |
| --- | --- | --- |
| `blaeck.html` | BLÄCK — the notebook that writes itself | On load the page inks itself in: the São Paulo→Stockholm route draws across the header, the headline wipes in like a pen stroke, a red-pen edit strikes "polished" → *in progress*, and the ARBETE PÅGÅR stamp thumps down. Ink-wash hover on note rows. Light + lamplight-dark themes. |
| `skrivbordet.html` | SKRIVBORDET — the illustrated desk | The hero is your desk drawn from above; every object (notebook, camera, printed part, microcontroller, coffee, budget phone) is a nav link with bilingual label chips and mouse parallax. Dark mode turns the room lights off and a warm lamp glow falls across the desk. |
| `plotter.html` | PLOTTER — generative ink, museum minimal | A generative pen-plotter draws a unique two-pen flow-field artwork live behind the Didot masthead on every visit, finishing after ~35 s with a plot caption. Everything else is strict Swiss typography — no cards, no shadows, only hairlines and ink. |
| `doismundos.html` | DOIS MUNDOS / TVÅ VÄRLDAR | São Paulo dusk and Stockholm winter meet in a living diagonal seam you can push with the pointer. Scrolling flies between the two homes: the background temperature travels warm→cool and a plane tracks a margin flight path GRU → ARN. Night mode adds stars and an aurora on the Stockholm side only. |

All built with the real site content, both themes token-based (plotter/doismundos included), `prefers-reduced-motion` fully honored (load sequences and canvases resolve to their finished static state), no external resources, verified in Chromium at desktop/laptop/mobile sizes with zero console errors.
